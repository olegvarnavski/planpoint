# PlanPoint

**Визуальный редактор интерактивных планировок для MODX Revolution 2.8.**

Загрузите изображение этажа, обведите помещения, задайте ключи квартир и назначьте готовую схему одному или нескольким этажам. PlanPoint хранит схемы отдельно от квартир и выводит изображение с SVG для существующего интерфейса сайта.

Текущая версия: **0.3.0-alpha**. Это рабочая альфа с ограниченным набором SVG-конструкций.

## Возможности

- Вкладка «Планировки» у настроенных ресурсов домов и этажей.
- Несколько схем для одного дома, назначение этажам и выбор диапазонов.
- Подложки PNG/JPG; интеграция с установленным mixedImage через настройки TV, по умолчанию `imgMigx`.
- Непрерывная обводка: линия до курсора, полупрозрачная область, замыкание по первой точке, следующий номер автоматически.
- Горизонтальные и вертикальные стороны по Shift или в постоянном режиме прямых углов.
- Перемещение вершин и SVG-точек, добавление и удаление вершин, история отмены/повтора.
- Вертикальная панель инструментов, свойства выбранного контура, подробная справка под редактором.
- Прямое редактирование номера и `data-i`; секция задаётся у общей схемы.
- Импорт SVG, просмотр и редактирование кода в локальном Ace, копирование и скачивание SVG/HTML.
- Просмотр, редактирование, назначение этажей, копирование и удаление через действия строки и контекстное меню.
- Защита от перезаписи устаревшей ревизией и конфликтов назначения этажей.
- Сниппет `PlanPointRender`, включая вывод без дополнительных чанков для файлового Fenom-шаблона.

## Требования

MODX Revolution **2.8.x**, PHP **7.4+**; экспериментально MODX **3.2.x**, PHP **8.1+**, MySQL с InnoDB, расширения DOM, mbstring и PDO MySQL. Для менеджера — современный браузер на ПК. Облачные Media Source не поддерживаются. Границы адаптации MODX 3 описаны в [MODX3.md](docs/MODX3.md).

Тестовые версии ядра — **2.8.5-pl** и **3.2.2-pl**. Локальные проверки выполнены на PHP 8.3 и MariaDB 10.11 через PDO MySQL. Это не заменяет проверку конкретной версии MySQL/PHP и дополнений рабочего сайта. [Подробности проверки](docs/VALIDATION.md).

## Быстрая установка

1. Скачайте именно файл `planpoint-0.3.0-alpha.transport.zip` из `dist/modx2` либо `dist/modx3` под вашу платформу, а не архив исходников GitHub.
2. Загрузите его в `core/packages/` и установите через менеджер пакетов MODX.
3. В пространстве настроек `planpoint` задайте ID шаблонов домов, подъездов и этажей.
4. Откройте сохранённый ресурс дома, добавьте схему, обведите помещения и назначьте этажи.
5. Подключите вывод в шаблоне сайта отдельно.

Обновление пакета с техническим именем `planpoint` сохраняет схемы и назначения. Предыдущий пакет с именем `planeditor` — отдельная установка: автоматического переноса из него нет, старый плагин `PlanEditorManager` следует отключить.

## Файловые чанки и Fenom

В существующем файловом чанке `chunks/catalog/plan/svg.tpl`:

```smarty
{set $scheme = $_modx->runSnippet('PlanPointRender', [
    'floorId' => $_modx->resource.id,
    'inner' => 1
])}
```

`$scheme` содержит только `<picture>` и `<svg>`. Если схема не назначена, возвращается пустая строка. Внешняя `.plan-svg`, улицы и вывод пинов квартир остаются в текущем файловом шаблоне. Дополнительные чанки создавать не требуется.

[Готовый пример svg.tpl](examples/chunks/catalog/plan/svg.tpl) сохраняет существующий вывод `msProducts` с шаблоном квартир 4. Это пример под конкретную структуру ресурсов; проверьте свои ID шаблонов и наследование улиц.

Ключи должны совпадать буквально: контур `data-i="x2-03"`, SVG-точка `data-pin="x2-03"`, HTML-пин и карточка квартиры с таким же ключом. Начальные нули сохраняются. PlanPoint не создаёт квартиры и не заменяет mFilter2.

## Ограничения

Поддерживаются замкнутые прямолинейные SVG-пути M/L/H/V/Z, включая относительные команды, и точки `circle[data-pin]`. Кривые, группы, transform, составные пути и активный код отклоняются. Сложные SVG не упрощаются автоматически.

История отмены хранится в открытом редакторе до сохранения или импорта. Автосохранения нет. При замене изображения координаты контуров сохраняются, viewBox и пропорции обновляются по новому файлу; положение контуров нужно проверить.

Пользователь с правом просмотра дома может работать со схемами; права файлового источника проверяются отдельно. Отдельного ограничения удаления схем только администратором пока нет. [Статус разработки](docs/STATUS.md).

## Структура

| Каталог | Содержимое |
| --- | --- |
| `core/components/planpoint` | PHP-сервис, схема БД, процессор, сниппет и плагин |
| `assets/components/planpoint` | Редактор, стили, коннектор и локальный Ace |
