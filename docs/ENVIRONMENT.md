# Подтверждённая среда проекта

- MODX Revolution 2.8.5-pl — подтверждено пользователем.
- Рабочая СУБД — MySQL, подтверждено пользователем. Переход на MariaDB не требуется и не планируется.
- Версия MySQL, версия PHP, ID шаблонов дома/подъезда ещё не установлены; на скриншоте показан Media Source ID 3 с относительными basePath/baseUrl `uploads/`.
- TV `imgMigx` ID 1: mixedImage, папка img, префикс qt-{rand}, удаление выключено, параметры ресайза пустые. Источник определяется по назначению TV в контексте дома.
- SQL установщика использует MySQL/InnoDB и PDO MySQL. Дополнительная СУБД для установки не нужна.
- MariaDB 10.11 использовалась только как локальный тестовый сервер. Её успешные тесты не подтверждают установку на конкретной рабочей версии MySQL.
- Таблицы modx_planpoint_* добавляются отдельно. Данные квартир, MIGX и существующие таблицы сайта не мигрируются.
