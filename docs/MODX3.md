# MODX 3: первый этап адаптации, 0.3.0-alpha

Проверенная версия ядра — выпущенный MODX **3.2.2-pl**, PHP 8.3.6. Использовались исходники этого тега и зависимости из официального дистрибутива, не экспериментальная ветка 3.x.

## Что перенесено

- Явные имена моделей `MODX\Revolution\…` и Media Source через небольшой `PlanPointPlatform`.
- Отдельный выбор базового класса процессора. На MODX 3 он наследуется от `MODX\Revolution\Processors\Processor`.
- Сборщик, validator и resolver используют соответствующие классы транспорта/xPDO.
- Старые прямые подключения файлов ядра остаются только в ветке MODX 2.
- Сервис, SVG-формат, таблицы, ревизии, назначения и файловый вызов сниппета общие для MODX 2 и 3.
- Коннектор загружает штатный коннектор своего ядра.

## Два транспорта

`dist/modx2/planpoint-0.3.0-alpha.transport.zip` собирается на MODX 2.8.5 и содержит имена моделей MODX 2.

`dist/modx3/planpoint-0.3.0-alpha.transport.zip` собирается на MODX 3.2.2 и содержит namespaced-модели MODX 3.

Одинаковая сигнатура пакета нужна для сохранения технического имени и штатного обновления на соответствующей платформе. Выбирать следует архив из нужного каталога. Эти файлы не взаимозаменяемы; перенос сайта с MODX 2 на 3 пока не заявлен как проверенный сценарий.

## Что проверено

Настоящий xPDOTransport устанавливает пакет в отдельной тестовой БД. Проверены файловый Media Source, сохранение схемы, повтор запроса создания, назначение этажа, рендер и экранирование, реальный API-процессор, отклонение неверного ID, сохранность источника изображения при смене настройки, повторная установка. Проверка MODX 3 выполняется без глобальных алиасов `modX`/`modProcessor`.

Браузерные сценарии редактора проходят с реальными Ext JS, темой и базовым окном из MODX 3.2.2. API, ресурсная форма, файловый браузер и загрузки mixedImage в этом браузерном стенде частично подменены. Это не полный E2E-тест установленной админки.

## Что ещё проверить

1. Вкладку на полностью установленном MODX 3 с настоящей сессией менеджера, правами сотрудников и деревом ресурсов.
2. Загрузку с компьютера и повторное открытие штатного файлового браузера без подмен.
3. Совместимую с MODX 3 версию mixedImage. Адаптер по умолчанию отключён на MODX 3; работают стандартный выбор MODX и прямая загрузка PlanPoint. После проверки установленного mixedImage можно включить `planpoint.modx3_mixedimage=1` на тестовой копии.
4. Несколько контекстов, разные Media Source, ограничения пользователей.
5. MySQL рабочего сайта: локальный сервер проверки — MariaDB 10.11, не production MySQL.

До этих проверок пакет MODX 3 считается экспериментальным. Установка на рабочий сайт этим изменением не выполняется.
