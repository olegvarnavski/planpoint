# Проверка 0.3.0-alpha — 24.10.2026

## Среда

PHP 8.3.6; MODX 2.8.5-pl и выпущенный MODX 3.2.2-pl. Для MODX 3 использованы исходники тега v3.2.2-pl и vendor из официального дистрибутива этой версии. БД стенда — MariaDB 10.11 через PDO MySQL. Рабочая СУБД пользователя — MySQL; её конкретная версия здесь не проверялась. PHP 7.4 пока проверен только на уровне совместимого синтаксиса/использованных API, отдельного запуска интерпретатора 7.4 не было.

## Автоматические проверки

- PHP: 56 сценариев SQLite, 55 сценариев PDO MySQL/MariaDB. Отличие — отдельная SQLite-проверка неполной структуры при ERRMODE_SILENT. Проверены SVG, доступы/иерархия, ревизии, назначения и повторное назначение, копирование, сохранение/удаление, кеш, нормализация списка, повтор создания/копирования с ключами, конфликт payload, версия схемы и вырожденные контуры. Старые вырожденные схемы остаются доступными для публичного вывода без ослабления фильтра активного SVG.
- Геометрия: 12 существующих проверок Node.js.
- Браузер: один и тот же набор сценариев на Ext JS/теме/базовом окне MODX 2.8.5 и 3.2.2. Ленивая вкладка, непрерывное рисование, Esc, Ctrl+Z/повтор, Shift и ортогональное замыкание, общая точка для повторного ключа, строковый флаг show_pins=0, секция 2-A, прямой ключ, масштаб/панорамирование, сохранение, назначение/копирование/просмотр, Ace и импорт, отдельный mixedImage-экземпляр, повторный браузер, смена размера и Undo/Redo.
- Настоящий xPDOTransport: отдельно собранные пакеты для MODX 2 и 3 устанавливаются оригинальными классами ядер в отдельные БД. Проверены Media Source, сохранение, ключ повторного запроса, назначение этажа, рендер и экранирование, реальный API-процессор, неверный тип ID, сохранность источника после изменения настройки, повторная установка. На MODX 3 глобальные алиасы modX/modProcessor не загружаются.
- Обновление MODX 2: 0.2.2 устанавливается и заполняется в первом PHP-процессе, 0.3.0 устанавливается во втором. Исходные схема, назначение и изменённая системная настройка сохраняются. Проверка новым процессом соответствует обновлению ранее установленного пакета и не использует оставшиеся в памяти классы старой версии.
- Синтаксис собственных PHP/JS-файлов и git diff --check.

## Границы

Интеграционный стенд создаёт реальные таблицы/объекты MODX, но не проходит web setup и не загружает сторонние плагины сайта. Системные события в тестовой оболочке подавлены. Браузерный API, форма ресурса, Media Browser и сетевые загрузки mixedImage частично подменены.

Поэтому не заявлена полная E2E-совместимость с установленной админкой MODX 3, конкретной версией mixedImage, ограниченными ролями сотрудников, несколькими контекстами и production MySQL. Реальные загрузки с компьютера/URL и очистка кеша с плагинами сайта требуют проверки на его тестовой копии. MODX 3 остаётся экспериментальным.

## Повторение

Команды и обязательные переменные — в DEVELOPMENT.md. tests/run.php изменяет таблицы t_planpoint_* указанной тестовой базы. tests/integration.php требует PLANPOINT_ALLOW_DB_RESET=1 и удаляет только отдельную базу planpoint_ci_2 либо planpoint_ci_3 на переданном сервере. Никогда не направляйте эти тесты на рабочий сервер.
