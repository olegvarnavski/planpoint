# Проверка PlanPoint 0.2.0-alpha

Проверено локально на PHP 8.3, реальных классах MODX 2.8.5-pl и MariaDB 10.11 через PDO MySQL. Рабочая база пользователя — MySQL; установка на её конкретной версии пока не проверена.

- 46 PHP-сценариев: SVG, доступы, иерархия, назначения, ревизии, копирование, сохранение и удаления, точечная очистка кеша. Те же сценарии прошли с SQLite и PDO MySQL/MariaDB.
- 12 проверок геометрии в Node.js.
- Chromium + Ext JS из MODX 2.8.5: активная первая вкладка сохраняется; панель PlanPoint не создаётся до открытия своей вкладки; непрерывное рисование, линия до курсора, замыкание по первой точке; Enter не замыкает; общая точка для повторного ключа; перемещение/масштаб; прямое изменение ключа; Ctrl+S; поиск и действия строк; назначения/копирование/просмотр.
- Ace загружается из локальных файлов, отображает код, отправляет изменённый SVG на проверку и возвращает его в редактор.
- Адаптер проверен с JS mixedImage из публичного репозитория: отдельные ID поля, повторный выбор изображения, единый экземпляр браузера MODX, отсутствие изменения состояния формы ресурса. Сетевые загрузки mixedImage с компьютера/URL в этом стенде не проверялись.
- Реальный транспортный пакет установлен оригинальным xPDOTransport: элементы, события, файлы и таблицы присутствуют. Сохранение, назначение и рендер через установленный snippet и API processor работают. Повторная установка 0.2.0 сохраняет схемы, назначения и настройки без дублей. Обновление со старого технического имени не предусмотрено.
- Реальный modTemplateVar с настройками imgMigx, назначение отдельного Media Source, получение папки/ID источника и нормализация публичного пути проверены через классы MODX.

Не проверено на сайте пользователя: конкретная установленная версия mixedImage, её загрузки по URL/с компьютера, сочетание темы менеджера с другими плагинами, устранение наблюдавшейся пустой первой вкладки в реальном окружении, фактическая версия MySQL/PHP и вывод схем на страницах сайта. Это требует проверки установленного пакета на сайте. Существующие шаблоны, MIGX и app.min.js пакет не изменяет.

Браузерный тест: задать MODX_SOURCE (исходники 2.8.5), CHROME_EXECUTABLE (Chromium) и MIXEDIMAGE_JS (JS установленного mixedImage). Требуется Node.js с playwright. Затем node tests/browser.test.js.

0.2.2: браузерные проверки Esc после двух точек в окне Ext, отмена/повтор точки и замыкания, горизонтальная сторона по Shift, все стороны замкнутого контура в ортогональном режиме, новое изображение 1200×700 и соответствующий viewBox. Ручная визуальная проверка вертикальной панели и обычного блока справки.
