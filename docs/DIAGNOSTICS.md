Ошибки кеша появились одновременно в 12:22:59 и затронули lexicon_topics, scripts, includes, resource и menu. Это похоже на пересекающиеся операции очистки, но журнал не доказывает, какой запрос или плагин начал удаление. Сообщение «No such file or directory» само по себе не означает ошибку прав на папку.

В 0.1.0 модуль вызывал refresh только для раздела resource. Однако стандартный refresh в MODX вызывает общее событие OnCacheUpdate, на которое могут быть подписаны другие плагины. В 0.2.0 этот вызов заменён точечной очисткой затронутых ресурсов через modResource::clearCache(). Модуль сам не очищает lexicon, scripts, includes, menu и не вызывает глобальный OnCacheUpdate. Стандартное событие OnResourceCacheUpdate сохраняется.

Это уменьшает объём очистки и влияние на другие дополнения, но не является доказанным исправлением всех предупреждений из переданного файла. Код ядра, EasyBlacklist, Sendex, CustomURLs и REST-клиентов не изменялся. Предупреждения устаревших API могут остаться.

## Проверка после обновления

Зафиксируйте время проверки. Откройте дом, сохраните схему, переназначьте этаж. Посмотрите только новые строки журнала за этот промежуток. Если снова появляются предупреждения lexicon/scripts/menu, для определения инициатора нужны новые строки с временем и перечень плагинов, подписанных на OnCacheUpdate и OnResourceCacheUpdate. Не удаляйте файлы кеша параллельно с этой проверкой.
