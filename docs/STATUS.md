# Статус PlanPoint

Текущая версия — **0.3.0-alpha**, MODX 2.8.x и экспериментально 3.2.x. Источник текущего поведения: README, EDITOR и INTEGRATION. SPEC содержит исходное ТЗ и последующие уточнения; не все его пункты реализованы.

## Реализовано

Хранение схем отдельно от квартир; вкладки дома/этажа; выбор и загрузка PNG/JPG; адаптер mixedImage; редактирование прямолинейных контуров и SVG-точек; непрерывное рисование, ортогональный режим, отмена и повтор; прямое изменение ключей; локальный Ace и строгий импорт; назначения по этажам и диапазонам; копирование в другой дом; защищённые ревизии и снимки назначений; точечное обновление кеша этажей; вывод через snippet, включая режим без дополнительных чанков; транспортный установщик.

## Ограничения и дальнейшая работа

- SVG ограничен M/L/H/V/Z без групп, transform, кривых и составных путей.
- История геометрии не сохраняется между сохранениями/импортами или повторным открытием окна.
- Замена изображения сохраняет координаты, автоматического масштабирования геометрии под новый файл нет.
- Мобильный редактор не заявлен; основной сценарий — ПК.
- MODX 3 проходит поэтапную адаптацию; ограничения — MODX3.md. Облачные Media Source не поддерживаются.
- Интеграция статусов квартир после AJAX-фильтрации зависит от JS и структуры конкретного сайта.
- Подтверждение совместимости с конкретной версией MySQL/PHP и установленного mixedImage выполняется на тестовой копии сайта.
- Отдельная открытая лицензия для собственного кода не выбрана.

Тестовые границы подробно указаны в VALIDATION.md. До изменения формата хранения или поддержки сложного SVG следует обновить ТЗ, валидацию и тесты, не нормализуя импорт молча.
