# Установка и настройки

## Пакет

Скачайте `dist/modx2/planpoint-0.3.0-alpha.transport.zip` для MODX 2.8 либо `dist/modx3/planpoint-0.3.0-alpha.transport.zip` для MODX 3.2 (экспериментальный). ZIP, который GitHub создаёт через «Download ZIP», содержит исходники и не является транспортным пакетом MODX.

Загрузите transport.zip в `core/packages/`, найдите локальные пакеты в менеджере MODX и установите PlanPoint. Для обновления существующего `planpoint` удалять предыдущую версию не нужно. После обновления перезагрузите страницу менеджера с обновлением кеша браузера.

Старый `planeditor` не обновляется этим пакетом и не мигрирует автоматически. Отключите `PlanEditorManager`, чтобы два плагина не добавляли вкладки одновременно. Старые таблицы и изображения автоматически не удаляются.

## Системные настройки

Пространство имён — `planpoint`. ID шаблонов задаются через запятую.

| Настройка | По умолчанию | Назначение |
| --- | --- | --- |
| `house_templates` | пусто | Шаблоны ресурсов домов; заполнить обязательно |
| `section_templates` | пусто | Шаблоны подъездов/секций, если есть промежуточный уровень |
| `floor_templates` | `8` | Шаблоны этажей |
| `image_tv` | `imgMigx` | TV с настройками mixedImage |
| `media_source` | `0` | 0 — источник TV; явный ID — источник при работе без mixedImage |
| `image_folder` | `plans` | Папка прямой загрузки PlanPoint относительно источника |
| `modx3_mixedimage` | `0` | Разрешить адаптер проверенной на MODX 3 версии mixedImage |
| `floor_number_field` | `menutitle` | Поле номера этажа для отображения и диапазонов |

Иерархия: дом → этаж либо дом → подъезд → этаж. Вкладка появляется у сохранённых ресурсов подходящего шаблона. Дом и этажи должны быть в одном контексте.

## mixedImage

Если mixedImage установлен, используется его штатное поле с настройками указанного TV. Сам TV не требуется добавлять на шаблон дома. PlanPoint использует отдельные идентификаторы полей и не записывает изображение схемы в TV ресурса.

Настройте источник TV в контексте дома. Оставьте параметры ресайза пустыми, удаление файла выключенным. Кнопки: `clear,manager,pc,url`; обрезка в редакторе PlanPoint не предлагается. PNG/JPG проверяются сервером; лимит PlanPoint — 20 МБ. Обработка загрузок установленным mixedImage зависит от его версии и настроек сайта.

Папка и имя загрузки mixedImage берутся из TV. `image_folder` относится к прямой загрузке самого PlanPoint. Это разные механизмы.

## Проверка

Добавьте схему у дома, сохраните и назначьте одному тестовому этажу. На сайте отдельно подключите `PlanPointRender`. Сам установщик не переписывает шаблоны сайта, MIGX и JS-сборки.

## Данные и доступ

Таблицы `{prefix}planpoint_schemes`, `{prefix}planpoint_assignments`, `{prefix}planpoint_locks` создаются отдельно. Для менеджера требуется право просмотра дома; для изображений — права источника. Схемы и файлы при удалении пакета сохраняются. При удалении самой схемы её назначения снимаются. Общие изображения и файлы вне настроенной папки прямой загрузки сохраняются; внешние ссылки в произвольном коде сайта не проверяются.

Обновление с 0.2.2 добавляет таблицы requests/meta, не заменяя существующие схемы и назначения. Перед обновлением требуется резервная копия. Не устанавливайте транспорт другой платформы; см. MODX3.md и RELIABILITY.md.
