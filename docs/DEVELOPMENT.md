# Разработка и сборка

## Устройство

Техническое имя — `planpoint`; PHP-классы и элементы MODX — `PlanPoint*`. Менеджер добавляет вкладку лениво, не переключая исходную вкладку ресурса. JS рисует и редактирует контуры; сервер проверяет SVG, доступ к ресурсам и файлам, ревизии и назначения.

Схемы хранят исходный SVG и метаданные изображения. До визуальной правки исходная SVG-строка сохраняется без нормализации. Ревизии защищают сохранение и удаление; назначения сравниваются со снимком состояния. Записи неназначенных этажей сохраняют ревизии, чтобы обнаруживать последовательность назначение → снятие назначения. Операции с общими файлами сериализуются через таблицу блокировок. Кеш очищается только у затронутых этажей.

Основной API — `assets/components/planpoint/connector.php`, процессор `api`, операция в параметре `op`. Требуется сессия менеджера MODX. Операции: houses, list, get, save, floors, assign, floor-info, set-floor, copy, remove, image, upload, validate. Это внутренний API менеджера, а не публичный endpoint сайта.

## Сборка

Нужна тестовая установленная MODX 2.8.x с PHP и расширениями из README. Из корня исходников:

```bash
php _build/build.transport.php /absolute/path/to/site/config.core.php
```

Скрипт выводит путь готового transport.zip. Он использует штатный modPackageBuilder и добавляет namespace, настройки, snippet/plugin/chunks, файлы и установщик таблиц. Настройки пользователя и базовые чанки при обновлении не перезаписываются; snippet/plugin обновляются.

Версия задаётся в `_build/build.transport.php`; при выпуске обновляйте версию ресурсов менеджера в плагине, CHANGELOG и пакет в `dist`. Не добавляйте конфиги установленного сайта, пароли, файлы кеша или пользовательские загрузки.

## Проверки

PHP-сценарии требуют DOM, mbstring и PDO SQLite по умолчанию:

```bash
php tests/run.php
node tests/geometry.test.js
```

Для отдельной одноразовой тестовой базы MySQL:

```bash
PLANPOINT_TEST_DSN='mysql:host=127.0.0.1;dbname=planpoint_tests;charset=utf8mb4' \
PLANPOINT_TEST_USER=local_test_user \
php tests/run.php
```

Тест удаляет и пересоздаёт таблицы `t_planpoint_*` в указанной базе: используйте только отдельную тестовую базу. Пароль при необходимости задайте переменной `PLANPOINT_TEST_PASSWORD` локально, не сохраняйте его в репозитории.

Браузерные тесты используют настоящий Ext JS из исходников MODX, локальный HTTP-сервер с тестовым API, Chromium и JS mixedImage:

```bash
npm install --no-save playwright
MODX_SOURCE=/absolute/path/to/revolution-2.8.5-pl \
CHROME_EXECUTABLE=/absolute/path/to/chromium \
MIXEDIMAGE_JS=/absolute/path/to/mixedimage.js \
node tests/browser.test.js
```

API и загрузки mixedImage в браузерном тесте частично подменены. Проверка UI не заменяет установку транспорта, проверку PHP-процессора и реальную загрузку файлов на сайте. Точные границы выполненных проверок — в VALIDATION.md.

## Сторонние компоненты

Ace включён локально с лицензией в vendor/ace. mixedImage, pdoTools, miniShop2, mFilter2 и MODX в исходники модуля не включены. Для интеграции с конкретным сайтом используйте его установленные версии и соглашения ключей. Не меняйте систему хранения квартир ради вывода схем.
