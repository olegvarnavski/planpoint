# PlanPoint 0.2.2-alpha

Вертикальные инструменты слева; подробная справка под редактором без фиксированной нижней панели. Esc обрабатывается в capture-фазе до Ext JS. Undo/redo до 100 геометрических действий. Shift и постоянный режим прямых углов. Секция только общая. При замене изображения обновляются viewBox и пропорции, выполняется вписывание. Убраны подтверждения удаления контура и двойное подтверждение импорта; успешное удаление схемы не открывает информационное окно.

# PlanPoint 0.2.1-alpha

Параметр `inner=1` у PlanPointRender возвращает только picture + svg, без чанков и внешней обёртки. Без назначенной схемы возвращает пустую строку. Позволяет оставить текущий файловый chunks/catalog/plan/svg.tpl и всю его Fenom-логику.

# PlanPoint 0.2.0-alpha

- Новое техническое имя: пакет и namespace `planpoint`, таблицы `{prefix}planpoint_*`, классы и элементы `PlanPoint*`, пути `components/planpoint/`.
- Отдельная чистая установка вместо обновления `planeditor`. Старые таблицы не переименовываются и не удаляются, данные автоматически не переносятся. Прежний плагин следует отключить перед использованием нового.
- Компактный редактор: иконки с подсказками, три вкладки, минимальные свойства выбранного контура, нижняя подсказка на всю ширину.
- Прямое редактирование номера/секции/data-i без кнопок применения.
- Линия до курсора, превью заливки и подсветка первой точки. Замыкание только по первой вершине. Enter не завершает контур. Непрерывное рисование и последовательные номера, Esc отменяет черновик и затем возвращает выделение.
- mixedImage с настройками TV `imgMigx`, независимые значения изображений схем. Очистка без удаления файла. Повторный файловый браузер MODX переиспользуется.
- Ace для кода/импорта, локальные ресурсы, копирование и скачивание SVG/HTML.
- Действия в каждой строке таблицы и контекстное меню: просмотр, редактирование, этажи, копирование, удаление.
- Номера и диапазоны этажей в таблице. Назначение относится к конкретной схеме.
- Ленивая инициализация вкладки сохраняет активную первую вкладку ресурса.

Ограничения прямолинейного SVG первой альфы остаются: M/L/H/V/Z без кривых, групп и transform. См. README.md.
